# Jīngāng bōrě bōluómì jīng 金剛般若波羅蜜經 (T236b)
*Vajracchedikā Prajñāpāramitā (Bodhiruci's Translation, Alternative Recension)*
by [[菩提流支]] (Bodhiruci, 譯)

## About the work

A single-fascicle alternative recension of Bodhiruci's *Vajracchedikā Prajñāpāramitā* translation. Signature: 「元魏留支三藏奉詔譯」 (with the abbreviated form 留支 for 流支). The text is a textually slightly different state of the same Bodhiruci translation as [[KR6c0024|T236a]]. For the *Vajracchedikā* tradition broadly, see [[KR6c0023|T235]].

### Prefaces

No preface or postface; only the canonical translator-signature.

### Abstract

T236b is the parallel-recension companion of T236a in the Sòng / Yuán canonical traditions; the same translation transmitted in slightly different textual state. Modern scholarship treats the two as a single Bodhiruci translation in different manuscript-traditions; the two-fold Taishō encoding preserves both states.
