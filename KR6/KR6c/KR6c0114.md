# Jīngāng bānruò bōluómì jīng zhuàn wàizhuàn juànxià 金剛般若波羅蜜經傳外傳卷下
*The Diamond Sūtra: Tradition-and-Outside-Tradition, Lower Juan*
[anonymous]

## About the work

A **partial anonymous Dūnhuáng-recovered commentary** preserved as T85 no. 2742, with only the **lower juan (卷下)** surviving. The catalog title — *zhuàn wàizhuàn* 傳外傳 ("tradition-and-outside-tradition") — is unusual: it appears to designate a commentary that combines a *zhuàn* (received-tradition) layer with a *wàizhuàn* (outside-tradition / supplementary-discourse) layer. The lost upper juan presumably contained the prefatory framework and early sūtra-text exposition. *notBefore* / *notAfter* = **600–900**. Catalog dynasty 唐.

### Abstract

The surviving lower-juan fragment treats the closing *Vajracchedikā* themes through a sophisticated **Madhyamāgama-Yogācāra synthesis**. Sample passage: *fǎ wúwǒ ruò yǒu bǐ wǒjiàn shìjiàn suǒ shè; púsà rù xiāngyìng sānmèi shí, bù fù fēnbié; jí cǐ guānchá wéi rù fāngbiàn, púsà zé rén wúfēnbié yě; yīqiè fǎ zé fǎ wúfēnbié yě* 法無我若有彼我見是見所攝。菩薩入相應三昧時不復分別 ("Dharma-non-self: if there be that 'self-view,' it is encompassed by the seeing-aggregate; the bodhisattva, entering the corresponding samādhi, no longer makes distinctions"). The commentator draws explicitly on **śamatha-vipaśyanā** (奢摩他 / 毘鉢舍那) doctrinal pairing as part of the **trí śīla-samādhi-prajñā** (*zēngshàng xīn / zēngshàng huì / zēngshàng jiè* 增上心 / 增上惠 / 增上戒) higher-training schema. This is one of the more rigorously Yogācāra-system commentaries in the Dūnhuáng cluster.
