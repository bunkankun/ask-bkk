# Gǔ zūnsù yǔyào mùlù 古尊宿語要目錄

*Table of Contents for the Essential Sayings of the Ancient Venerable Masters* — companion table-of-contents by [[道忠|Mujaku Dōchū]] 無著道忠 for the Northern-Sòng compact recension [[KR6q0263]] of the ancient masters' sayings. Parallel to Dōchū's earlier [[KR6q0260]] (table-of-contents for the expanded 48-juan *Gǔ zūnsù yǔlù*).

## About the work

A one-juan bibliographic table-of-contents for a parent canonical text, X68 n1316. Companion to [[KR6q0263]] *Gǔ zūnsù yǔyào*.

See [[道忠|Mujaku Dōchū]]'s person note and [[KR6q0260]] for context on Dōchū's table-of-contents scholarship.

Dating: *notBefore* 1680; *notAfter* 1744 (Dōchū's productive-scholarship period).
