# Bǐqiū tīngshī jīng 比丘聽施經
*Sūtra of the Monk Heard-of-Giving*
translated by [[曇無蘭]] Tánwúlán / Dharmaratna (譯)

## About the work

The *Bǐqiū tīngshī jīng* (T504) is a one-fascicle short sūtra translated by [[曇無蘭]] Tánwúlán — also written as [[竺曇無蘭]] (cf. *Ānán qī mèng jīng* [[KR6i0124]] which uses the longer form). The protagonist *Tīngshī bǐqiū* 聽施比丘 is a monk whose name means "Heard-of-Giving" (Sanskrit *Śrutadāna*).
