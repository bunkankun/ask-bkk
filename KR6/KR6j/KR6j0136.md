# Dǐnglúnwáng dà màntúluó guàndǐng yíguǐ 頂輪王大曼荼羅灌頂儀軌
*Great Mandala Consecration (Abhiṣeka) Ritual Manual of the Crown-Wheel-King*
by [[𧦪弘]] (compiler, 集)

## About the work

A one-fascicle Esoteric *abhiṣeka* (灌頂 *guàndǐng*, consecration) ritual manual for the Crown-Wheel-King mandala, compiled by the otherwise obscure Táng editor **𧦪弘** ([[𧦪弘]]).

### Abstract

The text provides the *abhiṣeka* ritual sequence for the Crown-Wheel-King practice — the formal consecration ceremony by which an Esoteric *ācāryā* admits a disciple to the Crown-Wheel-King mandala practice. The composition is conventionally placed in the late Táng period.
