# About this folder

This folder is intended for research notes and other material that will not be published.  It is mainly useful for researchers who would like to contribute to the project by providing updated entries for texts in the public part of the catalog, while also maintaining a record of research observations, questions etc.  

Obsidian can be configured to place any new note you create with the standard template into this folder, rather than somewhere else. This is configured as follows:

Open the settings dialog, usually by clicking on the gear or cog wheel. On the left side, select 'Files and links'.  Find the item 'Default location for new notes', which is probably set to 'Vault folder'. Go to the drop down and select 'In the folder specified below'.  This will add a new line below, which allows you to select 'Notes' as the destination. Close the settings and new notes should appear here.
