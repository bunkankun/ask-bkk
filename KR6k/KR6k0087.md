# Fànwǎng púsà-jiè-jīng yìshū fā-yǐn shì-yì 梵網菩薩戒經義疏發隱事義
*Auxiliary Notes on the Fā-yǐn Sub-Commentary*
by [[袾宏]] (Zhūhóng, 述)

## About the work

A one-fascicle auxiliary note-collection accompanying Zhūhóng's *Fā-yǐn* sub-commentary ([[KR6k0086]]). Provides supplementary explanations of doctrinal points and historical references in the parent work.

### Prefaces

Author: 明雲棲袾宏.

### Abstract

The *shì-yì* "factual meaning" is a standard auxiliary genre supplementing main commentaries with historical and lexical clarifications. Together with the parent *Fā-yǐn* and the polemical *Wèn-biàn* ([[KR6k0088]]), this text completes Zhūhóng's *Fànwǎng* exegetical project.
