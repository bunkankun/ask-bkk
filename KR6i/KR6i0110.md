# Chírén púsà jīng 持人菩薩經
*Sūtra of the Bodhisattva Person-Holder*
translated by [[竺法護]] (Zhú Fǎhù / Dharmarakṣa, 譯)

## About the work

The *Chírén púsà jīng* (T481) is a four-fascicle Mahāyāna sūtra translated by Dharmarakṣa 竺法護 ([[竺法護]]). The protagonist's name *Chírén* 持人 ("Person-Holder") translates Sanskrit *Lokadharma* or possibly *Sattvadhāraka*. The Taishō header cross-references No. 482 — Kumārajīva's [[KR6i0111]] *Chíshì jīng* (持世經), which is a translation of the same Indic text.

### Prefaces

The text opens directly with the canonical *jīngshǒu* formula. The colophon attributes the translation to Dharmarakṣa.

### Abstract

This text and Kumārajīva's later [[KR6i0111]] *Chíshì jīng* (T482) are translations of the same Indic *Lokadhara-paripṛcchā-sūtra*. The doctrinal content concerns the bodhisattva's *vyūha-kṣetra* (array-field) — the way a bodhisattva supports beings through wisdom and merit. The text is doctrinally close to the *Aṣṭasāhasrikā* and other early *prajñāpāramitā* literature.

Translation dated to Dharmarakṣa's productive period (266–308 CE).
