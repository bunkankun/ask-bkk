# Fóshuō Fànmónán guówáng jīng 佛說梵摩難國王經
*Sūtra of King Brahmadatta*
(translator unknown)

## About the work

The *Fóshuō Fànmónán guówáng jīng* (T521) is a one-fascicle anonymous short sūtra. *Fànmónán* 梵摩難 likely transliterates *Brahmadatta* (a stock royal name in Indic narratives).

### Prefaces

The text opens with the canonical formula. There is no surviving translator attribution.

### Abstract

A short *avadāna*-style narrative on a king's encounter with the Buddha. Unattributed translation; the broad pre-Sui dating bracket (200–600 CE) is standard for such anonymous texts.
