# Fóshuō lǎomǔ nǚ liù yīng jīng 佛說老母女六英經
*Sūtra of the Old-Woman's Six Heroes*
translated by [[求那跋陀羅]] (Guṇabhadra, 譯)

## About the work

The *Fóshuō lǎomǔ nǚ liù yīng jīng* (T560) is a one-fascicle Liú-Sòng translation by Guṇabhadra 求那跋陀羅 ([[求那跋陀羅]]). The text is part of the "old woman" cluster (cf. [[KR6i0191]], [[KR6i0193]]).

### Prefaces

The text opens with the canonical formula.

### Abstract

A short sūtra parallel to [[KR6i0191]]. The "six heroes" (六英) of the title refers to six elements or six contemplative aspects associated with the old woman's question. Translation dated to Guṇabhadra's productive period (435–468 CE).
