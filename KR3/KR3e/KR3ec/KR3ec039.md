# Běncǎo Bèiyào 本草備要 (variant transmission)
*Essentials of the Materia Medica, Prepared for Use* — a parallel-edition witness
by [[汪昂]] (Wāng Áng, 1615–1694, 清)

## About the work

KR3ec039 is a parallel transmission of Wāng Áng's *Běncǎo bèiyào* — the same work as [[KR3ec038]] — preserved separately in the 漢學文典 collection, likely a different printed edition (the catalog meta gives the same title, same author, same dynasty). The duplication reflects the standard editorial practice of including variant editions of the same work as independent catalog entries when they exhibit substantive textual differences. The local repository preserves only a header file for KR3ec039, suggesting that this entry serves as a placeholder for an alternative imprint.

For substantive discussion of the *Bèiyào*, see [[KR3ec038]]; this entry is a minor textual witness rather than a separate work.

### Prefaces

The local repository contains only the mandoku header file. The parent edition KR3ec038 preserves the substantive content.

### Abstract

This is a variant-edition witness to the same *Běncǎo bèiyào* of Wāng Áng (1683 / 1694) catalogued under KR3ec038. The differences between this entry and KR3ec038 are bibliographic — different imprints — rather than textual or authorial; both are Wāng Áng's *Bèiyào*. For full bibliographic, biographical, and analytical discussion, see KR3ec038.

The two entries together reflect the wide diffusion of the *Bèiyào* in early-Qīng commercial publishing — multiple Húīzhōu and Jiāngnán imprints competed in the market, and the 漢學文典 collection preserves several of them.
