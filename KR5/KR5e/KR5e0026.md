# Dòng xuán Líng bǎo xuán mén dà yì 洞玄靈寶玄門大義

*Dòngxuán Língbǎo Great Purport of the Mysterious Gate*

Anonymous; Táng (7th century)

An early-Táng **systematic doctrinal treatise** on Daoist teachings — an important precursor / source for Mèng Ānpái's later **Dào jiào yì shū** ([[KR5e0031]]). Preserved as **DZ 1124** / CT 1124 (Tài píng bù 太平部).

**Dating.** 7th century. Dynasty: 唐.
