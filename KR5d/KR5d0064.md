# Líng qí běn zhāng zhèng jīng 靈棋本章正經

*Orthodox Scripture of Original Stanzas for Spirit-Chess Divination*

attributed to [[顏幼明]] (Yán Yòumíng)

An **Eastern-Jìn divinatory text** using the **spirit-chess** (*líng qí* 靈棋) oracle — a set of twelve inscribed pieces (*tokens*) which are cast and interpreted by a rubric of stanzas. Preserved as **DZ 1041** / CT 1041 (Tài xuán bù 太玄部).

**Dating.** Eastern Jìn. Dynasty: 東晉.
