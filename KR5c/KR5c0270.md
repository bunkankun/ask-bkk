# Huáng tíng dùn jiǎ yuán shēn jīng 黃庭遁甲緣身經

*Yellow-Court Dùn-jiǎ Body-Association Scripture*

Anonymous; Táng

A Táng Daoist scripture integrating the **Huáng tíng** 黃庭 (Yellow Court) meditation-framework with the **dùn jiǎ** 遁甲 divinatory tradition, associating both with the practitioner's **body** (*yuán shēn* 緣身). Preserved as **DZ 873** / CT 873.

**Dating.** Táng. Dynasty: 唐.
