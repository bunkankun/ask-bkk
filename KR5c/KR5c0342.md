# Tōng xuán mì shù 通玄祕術

*Secret Techniques for Communicating with the Mystery*

by [[沈知言]] (Shěn Zhīyán) — late Táng Daoist alchemist

A late Táng / Five-Dynasties **alchemical instruction-text** on esoteric techniques for "communicating with the mystery" (*tōng xuán* 通玄). An earlier version attested to the late 9th century. Preserved as **DZ 942** / CT 942 (*Dòngshén bù, Zhòng shù lèi* 洞神部眾術類).

**Dating.** Late 9th / early 10th century. Dynasty: 唐-五代.
