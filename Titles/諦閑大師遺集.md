# 諦閑大師遺集

*Dìxián dàshī yíjí*

Early-Republican collected-works compilation of the late-Qīng Tiāntái master [[諦閑]] Dìxián (1858–1932); contains the complete Lèngyán jīng zhǐwèi shū [[楞嚴經指味疏]] commentary project, of which only the prefatory fascicle ([[KR6j0721]]) entered the Xùzàngjīng.
