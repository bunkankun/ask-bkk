# 正宗心印

Chán genealogical-cum-doctrinal record of the orthodox-line (*zhèngzōng* 正宗) mind-seal transmission, the parent compilation to which the late-Míng *Zhèngzōng xīnyìn hòuxù liánfāng* ([[KR6q0047]]) is a continuation.
