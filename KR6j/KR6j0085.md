# Huǒhūm guǐ biélù 火吽軌別錄
*Separate Record of the Fire-Hūṃ Ritual* (anonymous)

## About the work

A one-fascicle anonymous Esoteric ritual text, paired with the *Huǒhūm gòngyǎng yíguǐ* ([[KR6j0084]], T18n0913). The title's *biélù* 別錄 ("separate record") indicates that this is a supplementary text — perhaps an alternative recension or accompanying notes — to the main *Huǒhūm* ritual.

### Abstract

The text supplements the main *Huǒhūm gòngyǎng yíguǐ* with additional ritual prescriptions, alternative *mantra*-mudrā arrangements, or supplementary notes. Anonymous transmission and conventionally dated to the late Tang period.
