# Hǎiruì 海瑞

Mid-seventeenth-century Línjì Chán monk, dharma-heir of [[聆|Lǎnshí Líng]] 懶石聆 in the Pòshān / Zhàngxuě Sichuan sub-line. Head compiler (*děng lù* 等錄) of [[KR6q0432]] 《懶石聆禪師語錄》 (Jiāxīng Canon J28 B218), working with direct-recorder [[真蘊]] Zhēnyùn.

The 海-generation character is non-standard for the main Mìyún lineage-poem (which runs 通 → 行 → 性 / 本) but used as an alternative 34/35-generation marker in some sub-branches. Native place, lay surname, and lifedates unrecovered.
