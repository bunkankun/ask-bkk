This is a graphic-variant form of [[元稹]] (Yuán Zhěn, 779–831). The character 禛 (with 示 radical) appears in some catalog metadata as a print-shop confusion with 稹 (with 禾 radical) — the standard form being 元稹. See [[元稹]] for full biographical details.

The [[KR4c0068]] catalog meta uses the variant form 元禛, but the work title (*Yuánshì Chángqìng jí*) and all standard reference works (CBDB id 32248, *Xīn Tángshū*, *Báishì jí* epitaph) use the canonical 元稹.
