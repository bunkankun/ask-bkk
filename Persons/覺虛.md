# Juéxū 覺虛

Late-Míng *jiǎngshī* 講師 (lecture-master); solicited [[徐琳]] Xú Lín's official support for the 1607 re-cutting of the *Sìjiā yǔlù* edition that contains [[KR6q0079]] *Cóngróng lù*.
